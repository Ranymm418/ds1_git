titre : gestion des taches

1. Fonctionnalités :
   Le programme propose ses fonctionnalités :
   _) l’ajout d’une tache : on demande le titre apres on l’ajout a la liste (tache) si seulement si le titre n’est pas vide
   _) l’affichage des taches : on affiche toutes les taches avec leur numéro
   _) la recherche d’une tache : on fait la recherche des taches qui contiennent le mot clé écrite
   _) quitter : la fermeture du programme
2. les étapes réaliser :
   \*la creation du fichier main.py

- l’initialisation d’une liste(tache) vide ou on vas stocker les taches
- la creation des fonction qui fait l’ajout , l’affichage et la recherche des taches
- demander le choix de quelle fonction l’utilisateur souhaite realiser
- faire le test des differentes fonctionnalités du programme

3. methode d’execution :
   _) ouvrir le visual studio code (vs code)
   _) ouvrir le fichier main.py
   _) Faire le run de programme on cliquant sur le bouton run python file
   _) l’execution du programme et choisir l’option qu’ on souhaite la realiser
